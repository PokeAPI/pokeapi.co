## Information

PokeAPI stores sprites in a [Github repository](https://github.com/PokeAPI/sprites) that can be freely downloaded. Currently Pokemon, Forms, Badges, Items, Ribbons and Types' icons are present.

Whether a certain resource is available in the API or in the repository can be checked using the [Sprites Finder Tool](https://pokeapi.github.io/sprites/).

All available resources can be browsed using the [Sprites Browser tool](https://pokeapi.github.io/sprites/bulk.html) while the current Pokemon sprites coverage can be viewed with the [Sprites Audit tool](https://pokeapi.github.io/sprites/audit.html).
